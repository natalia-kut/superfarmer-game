# Superfarmer Game

A Python implementation of the board game Superfarmer with a pygame user interface.

## Features

- game logic for trading, breeding, and dice rolls
- player herd management and value calculations
- pygame-based UI with main menu and game screen
- sound effects and game assets

## Run

1. Create a virtual environment and install dependencies.
2. Start the game:

```bash
python main.py
```

## Project structure

- `superfarmer/` - core rules and game engine
- `pygame_ui/` - interface and widgets
- `assets/` - images used by the game
- `sounds/` - audio files
- `main.py` - application entry point
